### **1. PROJECT VISION & ORIGINAL GOAL**
The primary objective of the **Dexi Style** project was to engineer a high-fidelity, "mobile-first" cryptocurrency trading platform that mirrors the functionality and aesthetic of professional H5 exchange applications (specifically referencing the "Dexixz" architecture).

**Strategic Goals:**
- **Native Experience in Browser**: Deliver a seamless mobile UI that feels like a native app without the overhead of app stores.
- **Micro-Trading Hub**: Create a high-performance engine for binary options with instant execution.
- **Integrated Wealth Ecosystem**: Beyond trading, provide users with structured financial tools like mining, loans, and instant conversion.
- **Production Realism**: Reverse-engineer and implement data structures from live exchange APIs to ensure the local backend is ready for real-world integration.

### **3. TECHNICAL ENVIRONMENT & STACK**

The project was developed using a modern, high-performance stack optimized for real-time financial data.

- **Backend Architecture**: 
  - **Framework**: NestJS (Node.js) for a scalable, modular monolith.
  - **Database**: PostgreSQL for transactional data, managed via Prisma ORM.
  - **Caching & State**: Redis integration for high-speed state management.
  - **Real-time Communication**: Socket.io for live price feeds and order updates.
- **Frontend Architecture**:
  - **Framework**: Next.js 14 (App Router) with TypeScript.
  - **Styling**: Tailwind CSS for high-fidelity mobile UI.
  - **Animations**: Framer Motion for smooth transitions.
  - **Charting**: TradingView Lightweight Charts for professional analysis.
- **Deployment Infrastructure**:
  - **Containerization**: Full Docker support with `docker-compose.yml` for Postgres, Redis, Backend, and Frontend.
  - **Version Control**: Git-based workflow with optimized `.gitignore` for security and performance.
