# Mellonelay Engineering Skill Router

A Graphify-first compound engineering router for ChatGPT Work and Codex-style environments.

Package contents:
- `SKILL.md` — compact runtime behavior
- `references/` — routing, Graphify, Addy lifecycle, combo, evidence, inventory policies
- `scripts/validate_inventory.py` — verify candidate skill names against a markdown inventory
- `scripts/route_packet.py` — emit bounded worker packets
- `scripts/lint_skill.py` — deterministic package lint
- `agents/openai.yaml` — agent metadata
- `evals/evals.json` — starter evaluation scenarios

This package does not install, deploy, or modify project code by itself.
