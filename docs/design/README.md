# NEXI Design Documentation

## Current authority

The canonical Public frontend visual and interaction authority is:

`cloudflare-container-bootstrap/dexi-frontend/DESIGN.md`

Apply it together with:
1. current explicit owner decisions;
2. current Public source/runtime behavior where intentionally verified;
3. current backend/domain truth for all financial/market/auth state.

Do not create a second design authority under `docs/design`.

## Current design contract

The active frontend design contract preserves:
- the five recent accepted reference families: Quotes Hub, Spot/Margin, Options/Binary, wallet chooser, Wallet;
- near-black/OLED + Deep Liquid Violet interaction language;
- restrained glass, dense financial hierarchy, Geist typography;
- exactly five persistent mobile destinations: Dashboard, Spot/Margin, Options, Wallet, Earn;
- truthful `Live | Error | Closed` consumer market state;
- responsive coverage including 320/360/~390/412-430/tablet/desktop and short-height mobile;
- rendered responsive/accessibility proof before final visual completion.

## Historical lineage

Older synchronized design-system documents, Stitch packs, Office Agent decks, July targets, Sep-12/13 V2/V3 concepts, and generated concepts are lineage only when superseded by the current Public-local `DESIGN.md` or newer owner decisions.

Historical visual references remain retrievable from prior Git revisions. They are not active design authority.

Do not move archived design lineage back into active authority unless the owner explicitly re-adopts it.

## Rejected / superseded direction

Do not revive:
- the old `More` bottom-navigation model when it conflicts with the current five-tab dock;
- PostgreSQL as NEXI financial/application authority;
- provider/CDN logos as canonical NEXI asset identity;
- the superseded global wallet-access gate;
- `nexi_deep_liquid_violet_trading_concept.png`;
- `nexi_synthesized_spot_direction.png`;
- old V2/V3 visual concepts when they conflict with the current accepted reference family.

Current product/runtime truth always outranks historical visual artifacts.
