# Project Context: Dexi-Style Crypto Exchange ## 1. Tech Stack (Strict) * **Backend:** NestJS (Node.js), Prisma ORM, PostgreSQL, Socket.io. * **Frontend:** Next.js 14 (App Router), Tailwind CSS, Framer Motion, Lucide Icons. * **Charting:** `lightweight-charts` (TradingView). * **State:** React Hooks (useState/useEffect) - Keep it simple. ## 2. Design System ("Dexixz Mobile") * **Philosophy:** "Mobile-First H5 App". Native app feel in browser. * **Colors:** * Background: `#0a0e27` (Deep Navy) * Surface: `#121836` (Light Navy) * Success/Up: `#00C076` (Neon Green) * Danger/Down: `#FF4D4F` (Neon Red) * Text: White (`#ffffff`) or Muted (`#9ca3af`) * **Layout:** * NO Sidebar on mobile. Use fixed `BottomNav`. * Inputs: Large touch targets (48px+ height). * Buttons: Full width, sticky at bottom. ## 3. Architecture Rules * **Data Fetching:** Always use `process.env.NEXT_PUBLIC_API_URL` for endpoints. * **Real-time:** Use `socket.io-client` for Price/OrderBook updates. * **Configuration:** Never hardcode Game Settings. Fetch from `/api/binary/config`. * **Prisma:** When modifying DB, run `npx prisma db push` & `generate` immediately. ## 4. Specific "Don'ts" * Never use `alert()`. Use a custom Toast. * Never use generic CSS files. Use Tailwind utility classes.
