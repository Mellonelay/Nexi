## Authority and architecture mental model

1. Current owner/project directive and current source outrank old scripts/Kernel, obsolete browser owner routing and 2026-10 source snapshots. Current repository AGENTS.md governs unsuperseded deployment/packaging constraints. Preserve history, don't rewrite away evidence.
2. Three separately built surfaces behind VPS Nginx: Public Next.js 16 / React 19 mobile Web3 DApp browser, Admin TanStack Start/Router + Vite/Nitro desktop, and NestJS 12 API. UI data providers are not source of truth. TanStack loaders may execute server-side; user/token and context boundaries remain explicit.
3. Auth: Ethereum Mainnet SIWE chain ID 1, strict configured domain/URI, Redis stored single-use nonce 300s, wallet signature verification, user/session authorization. Admin has independent credential/session and server-side permissions. UI gating never substitutes server policy.
4. Accounting invariant: NestJS command/policy→single SQLite command gateway/atomic bridge→LedgerAccount/LedgerPosting, intent/idempotency, audit/Activity and Outbox/Inbox. Every effect must be exactly once even when BullMQ/Valkey wakeups or retries are at least once. SQLite WAL FULL and 5-second busy timeout protect durability; concurrent writes serialize. No frontend or Redis write becomes monetary fact.
5. Order/settlement: Wallet scopes Funding/Main, Spot, Margin, Options/Binary, Finance; Spot order reserve/partial fill semantics, Margin borrow/collateral liabilities, funding and withdrawal states, Mining and loan lifecycle are separately owned. Economic settlement is source-specific, not an arbitrary market display price.
6. Market: active/provider config→router/canonical pair→normalized provider events→ingest quote/Kline persistence vs best-effort reference trade/depth→Redis Pub/Sub→MarketGateway/Socket.IO Streams delivery→REST+socket Public and Admin. Socket.IO adapter recovery never backfills lost *upstream* reference events. 53 MarketPair instruments ≠ 55 MarketAsset records or 53x7 verified historical datasets.
7. Binary: Admin account default and eligible position override use guarded/versioned audited NestJS controls; research account allowlist from configured IDs. At expiry BinaryService chooses eligible research mode or source-constrained Binance Spot quote; D1FinancialCommandGateway (legacy name, SQLite authority) settles atomically. Simulated payout/expiry metadata and the bounded simulated candle/path are distinct produced data, and reference market streams are not settlement evidence.
8. Communication: customer↔operator canonical support thread and attachment/notification read model; recipient-selected POST /communications/messages intentionally Gone (410); ticket lifecycle retired. Outbox notifications are post-commit projections and cannot imply an economic mutation without the receipt.
9. Admin: eight operator workspaces, 21 NAV_GROUPS items, 13 contextual/compatibility/hidden route files, 34 named routes; permission-aware user interface. Auth/RBAC, config save and Public readback need separate evidence for each workflow.
10. Research/verification: 11 market repair tracked changes were uncommitted at the original document review but were later committed as `8d32b95a71ef`; Backend 33/33 + Public 17/17 focused tests and TS pass per dated receipt; 4 Postman GETs check older deployed baseline; Graphify is built at old commit 03cf396 and neither Graphify, Fallow nor scoped Archkeel certifies actual runtime. Backend artifact from November 17 247a38a, Public/Admin 4a478105; current candidate undeployed.
